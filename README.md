# Приложение для блога

Проект выполнен в рамках технологической (проектно-технологической) практики по направлению «Информационные системы и технологии», профиль «Веб-разработка».

## Назначение

Веб-приложение представляет собой блог с поддержкой многопользовательского режима. Пользователь регистрируется и входит в систему, создаёт посты (публичные или скрытые «только по запросу»), добавляет теги, подписывается на других авторов, оставляет комментарии. На главной странице отображается лента постов с возможностью фильтрации по подпискам и по тегам. В профиле пользователя отображаются его посты, подписки и подписчики. Все данные хранятся в localStorage браузера, серверная часть не требуется.

## Технологический стек

- HTML5
- CSS3
- JavaScript (ES6)
- localStorage (хранение данных в браузере)

## Структура проекта

- index.html — главная страница (лента постов, фильтры)
- login.html — страница входа
- register.html — страница регистрации
- post.html — создание и редактирование поста
- profile.html — профиль пользователя (посты, подписки, подписчики)
- css/style.css — стили интерфейса
- js/auth.js — регистрация, вход, выход, управление сессией
- js/posts.js — создание, редактирование, удаление и отображение постов
- js/subscriptions.js — подписки на пользователей, список подписчиков
- js/comments.js — добавление и отображение комментариев
- js/tags.js — сбор тегов и фильтрация постов по тегам

## Порядок развёртывания

1. Открыть терминал в папке проекта.
2. Запустить локальный HTTP-сервер:

   python3 -m http.server 8000

3. Открыть браузер и перейти по адресу http://localhost:8000/register.html.
4. Зарегистрироваться, затем войти под созданным логином.

## Примечание

Данные хранятся в localStorage браузера и привязаны к источнику (origin). Для корректной работы приложение следует открывать через HTTP-сервер (http://localhost:8000), а не через протокол file://. При очистке хранилища браузера данные удаляются. Для многопользовательского режима с общим доступом требуется серверная часть и база данных.
